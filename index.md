# Política de Privacidad — s1mple

**Última actualización:** 29 de octubre de 2026

## 1. Información general

Esta Política de Privacidad explica cómo funciona s1mple, una aplicación para Discord, y cómo se maneja la información durante su uso.

## 2. Información que se utiliza

El bot utiliza la información necesaria para ejecutar los comandos solicitados por los usuarios, como los datos incluidos en una interacción con el bot y la información básica que Discord proporciona para que funcione.

## 3. Almacenamiento de datos

El bot no mantiene una base de datos propia ni guarda intencionalmente información personal de los usuarios de forma permanente.

La información utilizada para procesar los comandos se maneja según el funcionamiento del bot y de Discord. La plataforma de alojamiento también podría generar registros técnicos, según su configuración.

## 4. Uso de la información

La información disponible se utiliza únicamente para ejecutar las funciones y los comandos del bot. No se vende información personal ni se utiliza para crear perfiles de usuarios.

## 5. Servicios de terceros

El bot funciona a través de Discord y puede depender de servicios de alojamiento para mantenerse en funcionamiento. Esos servicios pueden procesar información conforme a sus propias políticas de privacidad.

## 6. Seguridad

Se toman medidas razonables para evitar el acceso no autorizado a la información. Sin embargo, ningún servicio en línea puede garantizar seguridad absoluta.

## 7. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones del bot o la manera en que se utiliza la información. La versión actualizada se publicará en esta misma página.

## 8. Contacto

Si tenés preguntas sobre esta política o sobre el funcionamiento del bot, podés contactar a su desarrollador a través de Discord.
